## How Any AI Agent Can Continue Developing This Project (Zero Lock-In)
This project uses 100% pure open standards (Vanilla HTML5, CSS3, JavaScript ES2020, Web Worker DSP, lamejs MP3 encoder, Cloudflare Pages Functions + Worker TypeScript, and Cloudflare D1 SQLite). There is ZERO vendor lock-in.

### Exact Architecture & Key Files
1. `public/index.html` & `public/styles.css`:
   - Single-page mobile-first PWA (`360px+` Android friendly).
   - IMPORTANT: Whenever editing `public/styles.css`, copy its full contents into `<style id="singcraft-inline-css">...</style>` inside `public/index.html` as well.
   - Views: `#view-home`, `#view-sing`, `#view-mix`, `#view-blog`, plus standalone policy pages (`about.html`, `privacy.html`, `terms.html`, `refunds.html`, `contact.html`, `ads.txt`).
2. `public/app.js`:
   - Core frontend controller (`window.App`).
   - Hardware `<audio>` playback detached from WebAudio `AudioContext` so budget Android phones never stutter or crackle.
   - Supports YouTube Karaoke search + direct MP3/MP4 upload player (`#stageUploadedMedia`), auto & manual song lyrics lookup (`#lyricsOnlyQueryInput`), Firefox/Chrome Android `MediaRecorder`, draggable timeline & crop, Mix Studio Delete confirmation modal (`#deleteAudioModal`), 30-day Free Pro Pass on Gmail login, and `2/day` midnight download reset for Free users.
3. `public/dsp-engine.js`, `public/dsp-worker.js`, & `public/vendor/lame.min.js`:
   - Offline WebAudio vocal chain (EQ, compression, reverb, pitch smoothing) + compact `128 kbps` `.MP3` export (`~0.95 MB/min`) & `.WAV` export.
4. `src/worker.ts` & `functions/api/_worker_core.ts` & `schema.sql`:
   - Cloudflare Worker + Pages Functions API backed by D1 database `karomix-db` (`88b28623-1da8-42ff-8b52-479097f44650`).
   - Always copy `src/worker.ts` to `functions/api/_worker_core.ts` before deploying.

### Standard Deploy Commands (Any Terminal / CI / Agent)
```bash
cp src/worker.ts functions/api/_worker_core.ts
npx wrangler deploy
npx wrangler pages deploy public --project-name=singcraft-studio --branch=main --commit-dirty=true
```
